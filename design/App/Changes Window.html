The section no longer lists subtasks. It shows a strip with one column per subtask, height by lines changed: done columns grey, the running one amber, not-started ones dashed. Scale. The scope picker replaces the chips: a searchable list of every subtask with status, files and +N/−N. The strip under the toolbar is the fast path: click a column for one subtask, shift-click or drag across columns for a range. [ and ] step through subtasks one at a time, which is how you review a long run. A range diffs from the first subtask's start commit to the end of the last one, so it's one git diff, not a merge of many. Selecting a file lists the subtasks that touched it; click one to narrow to it. Sample data: a synthetic 33-subtask run (20 done, 1 running, 12 not started) built from this branch's real diffs.
