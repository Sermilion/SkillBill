3Where each value comes from

Fields marked new exist in runtime state but are not exposed through a JSON CLI command yet. The tray reads everything through two new read-only commands: skill-bill work board --format json, which lists every live item and recent finished items across repositories, and skill-bill work detail <workflow-id|invocation-id> --format json, which returns one item in full. Like the IDE plugins, the tray never reads the SQLite database directly.

Removed from the first draft
  • Queued goals. Skill Bill has no goal queue. Goals start when you run them.
  • Agent profile. Not a runtime concept. Replaced by model and effort.
  • "Total today" and "median goal time". No per-day goal metrics exist. Replaced by Needs you, Phases, and Done 24h counts, all computed from the board.
  • Hard-coded subtask phases ("analyze", "spec"). Replaced by real runtime phase ids.
  • Status contract v0.1. The IDE contract is 0.3. The tray pins its own board contract version.
Added
  • Standalone phases as their own section, with their step pipeline and current activity.
  • Planning state with plans saved and the planning wave.
  • Loop and pass counts, model and effort, and last agent activity.
  • Copyable CLI commands for resume and status in place of a Resume button.
  • Tray icon states and a right-click menu, because KDE may not deliver left clicks to tray icons.
  • Settings and a no database state.
