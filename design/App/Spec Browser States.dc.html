Run actions toolbar

The spec browser only shows, controls and opens specs. Its selection is local to the pane: it never changes the main panel, which follows only the left sidebar.

Pinned at the top of the pane, under the header. It acts only on a selected spec folder (a bundle): a goal runs the whole bundle, never one subtask, so selecting a subtask file, the parent spec or a plain folder leaves every button disabled. Start, Pause and Cancel keep their place and only enable or disable. Purge (eraser icon, right edge) appears once the spec has ever been started, and is disabled while the goal is running or pausing. Start's caret picks the agent. A paused goal shows a still half-dot; a running one pulses.
