Sona mobileDesign study · Linear mobile patterns on the linear-study tokens

Scope

The phone observes and controls. Goals, chats and agents run on the machine where Sona is installed. The phone connects over SSH when it opens, reads a snapshot, sends controls, and disconnects when it closes. Push notifications are the only thing that reaches the phone while the app is closed.

New for mobile

FeatureNotes
MachinesAdd over SSH: host, port, user; a phone key generated on device; trust on first use of the host key; Sona presence and version check. Several machines, one current.
Connection statesConnecting, unreachable with the last snapshot, host key changed (blocking), key rejected, Sona missing, Sona too old. Controls that fail say so and offer Retry. Nothing is queued.
PushDesktop app sends on board transitions through a Sona push relay to Firebase. The phone registers its FCM token on the machine over SSH during pairing. Stops while the desktop app is not running.
