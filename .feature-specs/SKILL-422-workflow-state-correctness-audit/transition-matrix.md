# SKILL-422 subtask 1: transition matrix

Categories: **lifecycle**, **phase/step**, **liveness**, **freshness**, **controls**, **progress**, **display**. Unsupported workflow row statuses (`cancelled`, `interrupted`, `superseded`, `idle`) are not `WorkflowStatus` values in `ClosedStatusTypes.kt`; do not persist invented enum members. **Idle** and **canceled** appear only as `IdeStatusLifecycleState` / `GoalRunnerLivenessState` display and liveness vocabulary. **Standalone supersede** is `StandalonePhaseStatusStore.supersedeActiveMonitors` writing `lifecycle_state=terminal` with `SUPERSEDED_MONITOR_ACTIVITY`, not a workflow row status.

## Explicitly unsupported as workflow statuses

`cancelled`, `interrupted`, `superseded`, `idle` — not `WorkflowStatus` enum members. Use **`abandoned`**, **`failed`**, **`paused`**, **`blocked`** on admitted workflow rows where production assigns them. **Canceled** presentation uses `IdeStatusLifecycleState.CANCELED` for `ABANDONED` workflow rows only. **Idle** liveness uses `GoalRunnerLivenessState`, not a workflow status. **Superseded** standalone monitors use `StandalonePhaseStatusStore.supersedeActiveMonitors`, not a workflow row transition.
